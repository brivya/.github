# Brivya

**Infrastructure for the Agentic Business Web.**

Brivya is building open **Business-to-Agent Infrastructure** that helps businesses expose real capabilities to AI agents safely and distribute the same Business Agent across multiple AI platforms.

> **One Business Truth, Many Distribution Projections.**

## What we are building

- **Brivya Core** — canonical business contracts and governed BusinessRuntime
- **Business Agent Manifest** — machine-readable business identity and capability declaration
- **Policy / Approval / Audit** — safe execution for real business mutations
- **REST + MCP** — protocol projections over the same Runtime semantics
- **TypeScript SDK + CLI** — code-first developer tooling
- **SemanticExperience** — platform-neutral interaction semantics
- **DistributionProfile** — multi-platform agent/service projection
- **Reference Profiles** — WorkBuddy and WeChat AI baselines
- **Extension Host** — permission-scoped extension and registry contracts
- **Reference E2E** — deterministic restaurant ordering / reservation scenario
- **Brivya Cloud / Studio / Publish** — future managed build, runtime and distribution services

## Architecture

```text
AI Traffic / Agent Host Platforms
            ↓
Distribution Profiles
            ↓
Canonical Business Agent
            ↓
BusinessRuntime
            ↓
Connectors
            ↓
Business Systems
```

Brivya does not let platform-specific SDKs, cards or Agent identity become business authorization truth.
